# 모터 임시 가정과 제어값

확인된 모터 정보는 **브러시 DC, 정격 전압 12 V, 모터 버스 입력 12 V**입니다. 정격 전류·스톨 전류·저항·인덕턴스는 제공되지 않았고, 사용자가 임시 추정값을 사용하고 이를 명시하도록 요청했습니다.

## 추정값

| 항목 | 임시값 | 근거·한계 |
|---|---|---|
| 모터 정격 전류 | 0.5 A | 초기 모델용 가정. 실제 데이터시트 정격 아님 |
| 스톨 전류 | 2 A | 초기 모델용 가정. 실제 구속 시험 결과 아님 |
| 권선 저항 | 6 Ω | 12 V / 가정 스톨 전류 2 A에서 계산 |
| 권선 인덕턴스 | 1 mH | 소형 DC 모터를 단순 RL로 시험하기 위한 가정 |
| 모델 역기전력 | 처음 0 V, 이후 2.4 V step | 제어 로직 시험용 외란. 실제 속도 모델 아님 |

이 값으로 모터의 실제 전력·허용 온도·토크 상수·기계 시정수·연속 허용 전류를 판단하지 않습니다. 회로의 입력 전압과 모터 정격 전압이 같아도 허용 전류가 결정되지는 않습니다.

## 초기 펌웨어 값

`Core/Inc/hb_config.h`에서 수정합니다.

| 매크로 | 초기값 | 뜻 |
|---|---|---|
| `HB_CURRENT_COMMAND_MAX_A` | 0.5 A | 허용 전류 지령의 상한 |
| `HB_SOFTWARE_TRIP_A` | 1 A | 원시 측정 전류 절댓값이 넘으면 latch 정지 |
| `HB_DUTY_MAX` | 0.50 | 왼쪽 상측 PWM 최대 듀티. 현재 ADC 시점과 한 쌍인 설정 |
| `HB_PI_KP_DUTY_PER_A` | 0.05 | 비례 이득, duty/A |
| `HB_PI_KI_DUTY_PER_A_S` | 5 | 적분 이득, duty/(A·s) |
| `HB_REFERENCE_SLEW_A_S` | 0.5 A/s | 지령 ramp 변화율 |
| `HB_CURRENT_LPF_ALPHA` | 0.2 | 20 kHz에서 제어 입력용 1차 필터 계수 |
| `HB_SENSOR_SENSITIVITY_V_A` | 0.200 V/A | 실제 IC3가 TMCS1108A3B일 때 |

지령 0 또는 run=0은 ramp 없이 출력 OFF 처리합니다. 양(+) 전류·정방향 초기 구동만 지원하며 음수 지령은 오류입니다. 50% 듀티 제한은 모터에 항상 12 V 평균을 인가하는 설정이 아닙니다. 이 제한으로 높은 속도의 역기전력을 이기지 못하면 지령에 도달하지 못하고 출력이 포화될 수 있습니다.

PI는 다음 순서입니다.

```text
I = (ADC - 무전류 ADC 평균) × 3.3 / (4095 × 0.200)
I_filtered += 0.2 × (I - I_filtered)
reference = slew_limit(command, 0.5 A/s)
error = reference - I_filtered
integral += Ki × error × 50 µs     (포화를 더 키우는 방향은 적분 중지)
duty = clamp(Kp × error + integral, 0, 0.50)
```

적분항도 ±0.50으로 제한합니다. 과전류는 위 소프트웨어 필터 이전의 측정값으로 판단하지만, TMCS1108와 R13/C20의 물리적 응답 지연은 여전히 있습니다. 기본값은 단락 보호 정격이나 실제 모터에서 안정하다는 보증이 아닙니다.

## 실제 사양을 알게 되면

1. 모터 모델명과 정격/최대/스톨 전류를 기록하고 임시값을 교체합니다.
2. PCB·배선·MOSFET·센서·전원의 허용 조건 안에서 지령·정지값을 다시 정합니다.
3. 낮은 전류 지령에서 측정값과 독립 전류계를 비교해 영점·감도를 확인합니다.
4. `Ki=0` 또는 작은 값으로 시작해 `Kp`를 조정하고, 낮은 `Ki`부터 정상상태 오차를 줄입니다. 발진·과전류가 나타나면 출력을 정지하고 원인을 확인합니다.
5. 지령 변화, 부하 변화, 전원·속도 조건을 바꿔 실측 기록을 남깁니다. `HB_DUTY_MAX`를 0.50보다 높이려면 ADC 시각·필터·실행 시간도 함께 재설계합니다.
